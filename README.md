# DeepCompose Mobile Preview

DeepCompose 手机端静态布局原型。所有作品、章节、会话、账号及任务均为虚构示例；不连接本地文件、电脑服务或模型 API。

预览地址：https://3470437923-cloud.github.io/deepcompose-mobile-preview/

主页面：工作台、作品、AI 对话、我的；含阅读、示例编辑、采用确认、主题切换和登录布局演示。
